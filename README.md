# 📊 Vrinda Store Data Analysis - Excel

## 📌 Project Overview

This project is an **Excel-based data analysis project** using the Vrinda Store dataset.

The objective of this project is to analyze sales data and identify important business insights related to **sales, customers, orders, categories, and sales channels**.

The project demonstrates practical Excel skills used in Data Analytics.

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

---

## 🔍 Analysis Performed

The project analyzes:

- Monthly sales performance
- Sales by gender
- Sales by age group
- Top-performing states
- Sales channels
- Order status
- Product categories
- Customer purchasing patterns

---

## 📊 Excel Skills Demonstrated

- Data Cleaning
- Data Formatting
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Visualization
- Dashboard Creation

---

## 💡 Key Business Insights

The analysis helps understand:

- Which months have the highest sales
- Which customer segments contribute the most sales
- Which states generate higher revenue
- Which sales channels perform better
- Which product categories are popular
- Customer purchasing patterns
